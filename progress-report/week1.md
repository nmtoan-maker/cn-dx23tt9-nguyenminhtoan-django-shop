# Báo cáo tuần 1

## 1. Nội dung thực hiện
- Tạo project Django
- Tạo repository trên GitHub
- Cài đặt Git trên server
- Push source code lên GitHub
- Mời giảng viên vào repository

## 2. Kết quả đạt được
- Project Django đã tạo thành công
- Code đã được quản lý bằng Git
- Repository hoạt động tốt trên GitHub

## 3. Khó khăn gặp phải
- Lỗi khi push code lần đầu (rejected fetch first)
- Lỗi xác thực GitHub (token)

## 4. Cách giải quyết
- Sử dụng lệnh git pull để đồng bộ
- Sử dụng GitHub Token thay cho password

## 5. Kế hoạch tuần sau
- Xây dựng chức năng cho website
- Tiếp tục cập nhật tiến độ lên GitHub

## 6. Hướng dẫn chạy project
python manage.py runserver
